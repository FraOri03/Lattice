1Lattice Present — Issue #96 surface mockups

Context read from the repo: today PresentationWorkspace.tsx is a single-selection editor — 44px slide rail with four hover buttons per thumbnail, one fixed 960×540 canvas, a 224px inspector holding x/y/w/h + one font size + fill/stroke, three hard-coded themes in THEME_COLORS, images as 4 MB data URLs, and a header row that mixes the deck title with PDF/PPTX export.

Design stance: keep every token from src/styles/index.css (13px Inter, #0d99ff accent, panel/panel2/bord greys, 6px control radius, 24px minimum target). Per §20 nothing gains a second toolbar row: one contextual bar, one right inspector, layers as a collapsible column, everything else contextual or in the palette. The canvas gets larger, not busier.

Deck used throughout: “Phase 19 — Surface upgrades review”, 42 slides, with charts linked to Q3 metrics (Sheet), stills from Photo mode and a diagram from Board — so linked content is visible rather than described.

1aEditor shell — 1440×900. Contextual bar replaces the title/export header; rail gains sections, hidden slides and presence; inspector is slide-level when nothing is selected; notes collapse to a strip.
