Turn 1 Lattice · Nodes (Graph) mode · redesign of the existing dark system

A spatial map of the project, with the chrome kept quiet

Same tokens as today — #1b1b1f canvas, #232327 panels, #0d99ff accent, the CardColor palette on nodes, the existing dash families on edges. What changes is the hierarchy: the two side panels stop being permanent walls, filters get two levels, labels get a budget and a collision pass, and every state change is written as a camera move rather than a jump cut. Every frame below is live — hover nodes, click them, search, zoom, toggle filters.

01 Project Graph — one node selected 1440 × 900 · primary state

The canvas owns the screen: 40px app bar, 40px graph strip, one docked 316px Inspector, everything else floats. API Architecture is selected — accent ring plus a soft halo, its six relationships lit in accent, the rest of the graph dimmed to 28% so the map stays legible instead of disappearing. Labels are budgeted: selection, neighbours and high-degree hubs first, then a greedy collision pass drops anything that would overlap.

A Hover — neighbourhood highlighting 120ms opacity transition

Hover beats selection for highlighting, exactly as the current renderer does. Design System grows ~13%, takes a light ring, and its eleven links become accent while the selected node keeps its blue ring — so you can survey a neighbour without losing your place. The tooltip is drawn in graph space so it travels with the node.

B Search — matches promoted, structure preserved ⏎ flies the camera in ~220ms

Matches take a yellow ring and keep their labels; non-matches drop to 20% but the shape of the project is still readable behind them. The result list shows the matched substring, the entity icon and a type · cluster subtitle, with the first row pre-selected for ↑↓ ⏎. Picking a result centres the camera rather than teleporting — try it, then use the minimap to jump elsewhere.

C Local Graph — a neighbourhood, not a filter nodes morph to new positions in ~320ms

One 30px bar carries the whole context: the way back, the root, a depth stepper and how much of the project you are looking at. No banner, no modal. The layout is radial from the root with second-hop nodes grouped under the first-hop node they came from, so the branches read as branches. Step the depth up and down to see the neighbourhood grow.

D Adjust — quick controls first, power controls below popover, not a third column

The old left panel becomes a 306px popover that never takes canvas width. Quick holds the four controls people actually reach for; Advanced keeps every power control that exists today, with the relationship rows showing their real dash pattern. The filters are live — untick Spreadsheets and the graph, the stats and the Adjust badge all change. Meanwhile the canvas keeps the old positions and says so, instead of blanking while it recalculates.

E 1280 × 800 — Inspector as an overlay canvas keeps its width

Below the docked tier the Inspector undocks into a 300px floating drawer with the shell's existing drawer elevation, so selecting a node no longer squeezes the graph and reflows every position. The secondary statistics (clusters) drop out of the bottom readout before anything else shrinks.

F Filtered-empty — explain, then offer the way back state coverage

An empty canvas always says why it is empty and what to do next; the graph never invents links, so "nothing here" is a filter problem, not a data mystery. Reset filters brings the whole project back in one click.
